# Tosin Adegoke portfolio

Static site for https://amoz33.github.io (HTML, CSS, JS; no build step).
Built on the WooDY template by HTML Codex (credit link kept in the footer, as the template license requires).

## Add your own images (optional)
- `assets/img/projects/<name>.jpg` replaces the automatic website preview. Names: schoolshell, gfperfect, abonik, bluedrops, gwpl-energy, gwpl-security, audiosphere, iccesd, fjsc, innerwheel, seun
- `assets/img/graphics/<name>.jpg` replaces the illustration for a design tile. Names: certificate, proposal, flyer, poster, banners, brochure

## Keep
The old `assets/imgs/` folder (certificate images image1.PNG and image2.PNG) is still used. Do not delete it.
